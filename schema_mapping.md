# BigQuery to Power BI Schema Mapping

## Table Schema Mapping
- **Patient_ID** (STRING) -> Case ID / Patient Identifier
- **Activity_Name** (STRING) -> Event Step / Process Stage
- **Timestamp** (TIMESTAMP) -> Event Start/End Time
- **Department** (STRING) -> Hospital Ward / Department
- **WaitTimeMinutes** (INT) -> Calculated Delay / Wait Duration
